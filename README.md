# poker-diary.com

Static site for the pokerDiary app (GitHub Pages, custom domain).

- `index.html` landing page, `privacy.html`
- `join/index.html` invite landing (`/join/<CODE>` is routed there by `404.html`)
- `.well-known/assetlinks.json` Android App Links (add the EAS upload and Play signing SHA-256s)
- `.well-known/apple-app-site-association` iOS Universal Links (replace TEAMID)
